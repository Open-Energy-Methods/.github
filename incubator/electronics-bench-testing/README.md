This folder preserves the controlled programme's master plan and a **complete cleaned source-package ZIP** on a GitHub branch, pending creation of a dedicated research repository. ## Research maturity

- Computational feasibility v0.1 includes **synthetic data only** and seven numerical/physics checks.
- A 54-run main physical test matrix is provisional; **no powered experiments or instrument calibrations have yet been authorized or completed**.
- Makerspace access, equipment verification, physical measurements and scientific novelty validation remain open.
- Future work will use controlled amendments, preserving this baseline rather than repeatedly redefining it.
