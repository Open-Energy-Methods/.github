# Security policy

EnerLint and related OEM repositories are early-stage research software and are **not** approved for safety-critical engineering decisions.

Please do not publish exploit details or sensitive input datasets in public issues. Use GitHub's **Report a vulnerability** feature in the relevant repository if enabled, or contact the maintainers via a private channel.

Security or numerical correctness findings must include the affected revision, reproducible steps, environment, and expected versus observed result where safe to share.

No response-time service-level agreement or commercial support commitment is currently offered.
